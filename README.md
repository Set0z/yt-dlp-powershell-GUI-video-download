> irm "https://raw.githubusercontent.com/Set0z/ytvd/refs/heads/main/ytvd.ps1" | iex
> ```

---

<h3 align="center">📌 Description</h3>
<br>

This project is a GUI built with PowerShell and Windows Forms.
It allows you to download videos from YouTubek.

  ✅ On YouTube, if multiple audio tracks are available, you can choose the language.

  ✅ Works only with YouTube.

  ---

<h3 align="center">⚙️ Requirements</h3>
<br>

  - yt-dlp.exe – required for downloading videos.

  - ffmpeg.exe – required if you want YouTube videos with audio merged into video.

  > - Without ffmpeg, YouTube downloads will be separated into .mp4 (video) and .m4a (audio).

  - PowerShell 5.1 or higher (comes with Windows 10 by default).

  ---

<h3 align="center">🖼️ Features</h3>
<br>

  - Simple graphical interface (no need to use the console).

  - Download from YouTube.

  - Audio track language selection on YouTube.

<h3 align="center">📌 Описание</h3>
<br>

Этот проект — это GUI, сделанный на PowerShell с использованием Windows Forms.
Он позволяет скачивать видео с YouTube.

  ✅ На YouTube при наличии нескольких звуковых дорожек можно выбрать язык.

  ✅ Работает только с YouTube.

---

<h3 align="center">⚙️ Требования</h3>
<br>

  - yt-dlp.exe – нужен для скачивания видео.

  - ffmpeg.exe – нужен, если требуется скачать видео с YouTube со звуком, объединённым с видео.

   > - Без ffmpeg будут скачиваться отдельно файлы .mp4 (видео) и .m4a (аудио).

  - PowerShell версии не ниже 5.1 (по умолчанию есть в Windows 10).

---

<h3 align="center">🖼️ Возможности</h3>
<br>

  - Простой графический интерфейс (не нужно пользоваться консолью).

  - Скачивание с YouTube.

  - Возможность выбора языка аудиодорожки на YouTube.
